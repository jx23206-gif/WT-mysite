# ワールドトリガー　トリガー設定サイト

## 概要
マンガ・アニメ「ワールドトリガー」のトリガーセット。それを再現し、自分専用のトリガー構成を作成・閲覧できます。

## 使用技術
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## 機能
- トリガー一覧の閲覧
- トリガーセットの作成
- 作成されたトリガーセットの閲覧
- 既存キャラクターのトリガーセットの閲覧

## 工夫した点・頑張った点
- 公式情報から、100名を超えるキャラクターの情報、50を超えるトリガーの情報がのっています。
- 木崎レイジにも対応しています。
- サイト中のトリガーホルダーや背景の画像も自作です。
- 文字が見やすいように背景色に背景画像の背景と同じ色を指定しました。

##追加（2026/5/25）
### SQLファイル'world_trigger_2.sql'を追加しました。
phpMyAdminからエクスポートしたものです。
4つのテーブルを使用しています。
- Charactersテーブル：ワールドトリガーに出てくるキャラクターの基本情報です。
- triggersテーブル：ワールドトリガーに出てくるトリガーの基本情報です。
- character_triggersテーブル：キャラクターが持つトリガーの情報です。
- user_trigger_setsテーブル：ユーザの名前とそのユーザが選んだトリガーの情報です。
